# Failure Modes of Low-Cost Wireless Sensor Nodes in Agricultural Fields

Yui Tanaka and Claire Moreau

## Abstract

We report three recurring failure modes of low-cost sensor nodes over four seasons: slow drift, sudden offsets and gaps caused by radio link failures. Comparing each node with the median of its neighbours detects drift earlier than any single-node indicator.
