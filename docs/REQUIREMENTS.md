# Requirements and their verification

> Generated by `python3 verify/trace.py` from `verify/requirements.toml` and the check registry — do not edit.
> `verify/run.sh` runs TLC on every model, then all tests; `tests/test_traceability.py` fails if any
> requirement is unverified, any link is broken or this file is stale.

**130 requirements**, every one with at least one verification. 17 are proved on a TLA+ model by TLC and linked to the code by conformance tests that replay every row of the model's table on the real implementation; the rest are verified by property tests (many generated inputs) and example tests.

| Method | Requirements |
|---|---|
| test | 114 |
| conformance | 19 |
| TLA+ (TLC) | 17 |
| property | 7 |

Methods: **TLA+ (TLC)** — an invariant or temporal property checked over every reachable state of the model; **conformance** — every sequence in the model's table (thousands) replayed on the real code, results equal; **property** — a law checked on hundreds of generated inputs; **test** — an example test.

See [verify/README.md](../verify/README.md) for the models, what each proves and the defects the verification found.
